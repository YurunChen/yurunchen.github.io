Main evaluation

The main Online evaluation uses 200 tasks: 142 Graft, 30 Refresh, and 28 Clarify. Each task runs once per condition for at most 20 steps. The same 200 tasks are also run as Computer-Use and as Offline Ego Use.

  • Computer-Use. Explicit instructions, with no first-person recording.
  • Offline Ego Use. The recording is available before execution.
  • Online Ego Use. Observations and requests arrive while the agent acts.

93 additional Online tasks combine multiple change types and are reported in the paper.
